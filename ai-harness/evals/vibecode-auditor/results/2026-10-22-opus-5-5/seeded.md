## Verdict
Safe to launch: no
TL;DR: The Supabase `service_role` key and the OpenAI key are both in `NEXT_PUBLIC_*` variables, so they ship in the browser bundle. The server also uses that service-role client everywhere, which bypasses all row-level security. On top of that, every API route is unauthenticated. Anyone can read any document, delete any user, run SQL injection against the database as the `postgres` superuser, grant themselves "pro" through a fake Stripe webhook, and run up the OpenAI bill. A live Stripe secret key and the database password also sit in a `.env.production` file that `.gitignore` does not exclude. Rotate every key in that file before doing anything else.

## Stack
Next.js 14.2.5 (App Router) · Supabase Auth · Supabase Postgres (supabase-js plus a raw `pg` pool) · Stripe Checkout · OpenAI gpt-4o · hosting not declared (no vercel.json or netlify.toml; `promptly.app` URLs) · builder: Lovable (`lovable-tagger` in devDependencies)
